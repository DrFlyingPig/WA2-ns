# WA2-ns 0.1.12 正式版发布报告

日期：2026-09-02

## 正式配置

- 应用标题：`WA2-ns`（无 D/P/F 诊断后缀）。
- 版本：`0.1.12`。
- 普通对白正文范围：`x=278..978`，有效宽度 700px，相当于 25 个 28px
  全角字格；第 26 个全角字会换行。
- 保留已确认的单换行软重排、按真实字形宽度测量、纵向字号自适应、逐字索引、
  两阶段对白推进、P2B 并行帧缓冲、立绘生命周期以及稳定音频路径。
- 不启用实机否决的 P3 静止画面重绘优化。F3/F4 的历史宽度也没有进入正式值；
  仅保留其后续验证正确的软重排实现。
- 系统设置恢复参考实现的三页完整项目：文字速度、自动等待、未读跳过、演出
  等待、确认框默认项、页面语音、长按快进、总/BGM/SE/语音音量、十组角色
  语音、三类文字窗透明度及 H 场景语音。`config.bin` 保持旧 24 字节布局，
  并兼容本轮早期 CFG2/version 2 扩展。
- 特别模式补齐两篇电子小说、168 个 CG 槽（14×12）、24 个场景回放、63 首
  BGM 和 5 段声优访谈；场景通过原版 `9999` 分派脚本及完整 replayMode
  编号回放，不再是占位入口。
- 新增独立 `wa2ns_system.bin` 保存全局已读、CG、场景和 BGM 解锁进度；只读
  合并现有存档并导入数据目录中的原版 `SYSTEM.sav`，不修改原文件。
- 不嵌入 demo、字体或任何游戏资源；运行时继续读取 `sdmc:/wa2`。

正式构建入口：

```powershell
python tools/build_switch.py --devkitpro D:\devkitPro --release
```

## 自动与数据验证

- 正式宏组合核心测试：200/200；包含特别模式表、24 路 replayMode、配置
  v3 往返、CFG2/version 2 与旧 24 字节配置迁移。
- framebuffer swizzle：与 libnx 参考结果一致，480 个任务、3,932,160 字节、
  四分片并发结果一致。
- PC 无窗口视觉回归覆盖设置三页、恢复默认确认框、CG/场景/BGM 两页状态及
  声优访谈页；另直接点击特别模式四个入口，分别进入 CG、场景、BGM、声优页。
  截图路径已隔离持久化，运行前后用户配置哈希与时间戳一致。
- 项目内真实数据探针确认 `9999.bnr`/`9999.txt` 存在；BGM 表 63 个唯一 ID
  均能在 `BGM.PAK` 的 66 个曲目 ID 中找到。
- 构建参数防混用测试通过：`--release` 会拒绝 `--with-demo` 和额外单变量诊断参数。
- 187 个真实文本表共 121,558 个非空候选页，在 700px 保守全角审计下：
  - 28px：121,412 页；26px：111 页；24px：17 页；22px：11 页；
  - 20px：6 页；18px：1 页；16px：0 页；
  - 达到 16px 仍无法完整容纳：0 页。

## 二进制验收

- 连续两次完整同名正式构建 SHA-256 一致；根目录与版本目录的 NRO、ELF、
  MAP、NACP 四项哈希也全部一致。
- `RenderAdvWindow` 的 ARM64 反汇编包含三处 `0x2BC = 700` 的宽度传值/比较；
  `672/784/920` 均未作为文本宽度值残留。
- NACP 直接读取为标题 `WA2-ns`、版本 `0.1.12`，无诊断后缀。
- NRO 头为 `NRO0`，资产头为 `ASET`，NACP 为 16,384 字节，RomFS 为 0 字节。
- 音频/线程/帧缓冲链接门禁通过：audout、SDL 线程至少 1MiB、引擎线程 4MiB、
  Tremor 不在 SDL 回调、P2B worker 已链接。
